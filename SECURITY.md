# Security Policy

## Supported versions

Only the latest published release of this repository is supported for security updates.

## Reporting a vulnerability

Please report suspected security issues privately by emailing:

security@majir.shop

You can also use GitHub private vulnerability reporting for this repository.

Please include:

- Repository name
- Affected file, version, or release tag
- Steps to reproduce, if available
- Potential impact
- Any proof of concept, logs, or screenshots that help explain the issue

Do not open a public GitHub issue for security vulnerabilities.

## Response

We will review valid reports, investigate the issue, and coordinate a fix before public disclosure when needed.

## Scope

This repository contains the Majir Claude plugin package. Security reports related to the plugin MCP configuration, skills, documentation, or release package are in scope.

The hosted Majir MCP server and backend services are maintained in separate repositories, but you can still report related concerns to security@majir.shop.
